## Intent (verbatim prompt)
"Monitor my corporate account for any urgent messages regarding 'Kid Sick' or 'School Closure.' If one comes in, immediately duplicate and forward it to my primary Google account so I don't miss it while away from my desk."

## Tool / step contract
| # | tool_id | action | approval | connector | active? | input keys |
|---|---------|--------|----------|-----------|---------|------------|
| 1 | outlook.search | scan corporate inbox for messages matching "Kid Sick" / "School Closure" | false | MS365 | false | query, folder, since |
| 2 | gmail.send | duplicate and forward the matched message to the primary Google account | true | Gmail | true | to, subject, body, sourceMessageId |

## Acceptance criteria (observable, testable — no bare "works/fast")
- AC1: outlook.search returns only messages whose subject or body contains "Kid Sick" or "School Closure" (case-insensitive), within the configured lookback window.
- AC2: For each matched message, gmail.send is called at most once, keyed by the source message's outlook message id (no duplicate forwards on re-scan).
- AC3: The forwarded email's `to` field equals the configured primary Google account address exactly.
- AC4: The forwarded email body contains the original sender, original timestamp, and the full original message text (byte-for-byte body copy, not a summary).
- AC5: When outlook.search returns zero matches, gmail.send is never invoked (no unconditional forward).
