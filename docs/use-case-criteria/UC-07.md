## Intent (verbatim prompt)
"Scan the most recent files I've opened or edited in my Google Drive workspace. Find anything labeled 'Home Maintenance' or 'Tax Receipts' and ensure a copy is backed up within my personal OneDrive storage directory."

## Tool / step contract
| # | tool_id | action | approval | connector | active? | input keys |
|---|---------|--------|----------|-----------|---------|------------|
| 1 | drive.list | scan the most recently opened/edited files in the Google Drive workspace | false | Google | true | workspaceId, sinceDate, labelFilter |
| 2 | onedrive.list | list existing files in the personal OneDrive backup directory, to check what's already backed up | false | MS365 | false | folderId |
| 3 | onedrive.upload | upload a copy of each matched Drive file into the OneDrive backup directory | true | MS365 | false | folderId, fileName, sourceFileId, content |

## Acceptance criteria (observable, testable — no bare "works/fast")
- AC1: drive.list's returned set is filtered to files labeled "Home Maintenance" or "Tax Receipts" (case-insensitive) among the recently opened/edited files, excluding unlabeled files.
- AC2: onedrive.upload is only invoked for a matched Drive file when onedrive.list shows no existing OneDrive file with the same `sourceFileId` (dedup against files already backed up).
- AC3: Each onedrive.upload request carries a `sourceFileId` reference back to the originating Google Drive file, so every backup copy is traceable to its source.
- AC4: onedrive.upload is invoked at most once per matched `sourceFileId` per run (idempotent — re-running the sync does not re-upload already-backed-up files).
- AC5: When drive.list returns zero matching files, onedrive.upload is never invoked (no unconditional uploads).
