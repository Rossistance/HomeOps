## Intent (verbatim prompt)
"Search through my family organization pages in Notion for any items marked 'Home Improvement Tasks.' For every item you find, automatically populate it as a brand new action item on my active Todoist list."

## Tool / step contract
| # | tool_id | action | approval | connector | active? | input keys |
|---|---------|--------|----------|-----------|---------|------------|
| 1 | notion.searchPages | search family organization pages in Notion for items marked "Home Improvement Tasks" | false | Notion | false | workspaceId, tagFilter |
| 2 | todoist.createTask | create a new Todoist action item for each matched Notion item | true | Todoist | false | projectId, content, sourceItemId |

## Acceptance criteria (observable, testable — no bare "works/fast")
- AC1: notion.searchPages' returned set is filtered to items explicitly tagged/marked "Home Improvement Tasks" (exact tag match), excluding unrelated pages.
- AC2: todoist.createTask is called once per matched Notion item, with `content` derived from that item's actual title/description text (not a generic placeholder string).
- AC3: Each created Todoist task carries a `sourceItemId` reference back to the originating Notion item, so every task is traceable to its source.
- AC4: todoist.createTask is not invoked a second time for the same `sourceItemId` on a re-scan (dedup against tasks already created on a prior run).
- AC5: When notion.searchPages returns zero matching items, todoist.createTask is never invoked.
