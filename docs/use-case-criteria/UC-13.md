## Intent (verbatim prompt)
"At 6:00 PM on weekdays, detect all active smart speakers set up throughout the home and broadcast an audio announcement saying: 'Dinner is ready, time to wrap up homework!'"

## Acceptance criteria (observable, testable — no bare "works/fast")
- AC1: The schedule trigger fires only on weekdays (Monday-Friday) at 18:00 in the configured local timezone, never on weekends.
- AC2: alexa.announce's target `deviceIds` are derived exclusively from the devices alexa.listDevices reports as currently online/active, excluding any offline or unpaired devices in the list result.
- AC3: The announced `message` text exactly equals "Dinner is ready, time to wrap up homework!" with no truncation, paraphrase, or added filler.
- AC4: alexa.announce is invoked at most once per triggering schedule tick (no duplicate/repeated broadcast bursts for a single 18:00 trigger).
- AC5: If alexa.listDevices returns zero active/online devices, alexa.announce is not invoked (no broadcast attempted with an empty device set).
