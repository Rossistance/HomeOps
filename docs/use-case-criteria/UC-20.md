## Design decision — the document reference lives in `task.notes` (ISS-001, HYP-005)
`homeops.attach_note_or_file_reference` attaches to an **event**, not a task (it requires `eventId`; see server/internal-functions.mjs). The source prompt asks to attach a reference to a **task card**. Rather than fabricate a task-attachment step or misuse the event tool, the skill stores the insurance-policy reference in the task's `notes` field, which is durable and retrievable. (If a first-class attachment is later required, the alternative is a companion event holding the attachment — documented, not built.)

- AC3: A list item "Buy wood screws" exists on the list `Weekend`.
- AC4: The skill contains NO `homeops.attach_note_or_file_reference` step (no fabricated/misused task-attachment).
