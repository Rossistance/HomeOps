## Intent (verbatim prompt)
"Locate the local school calendar spreadsheet saved on my hard drive, run an automated browser script to log into the school portal to pull the monthly nutritional information, and download the finished breakdown document directly to my local drive."

## Acceptance criteria (observable, testable — no bare "works/fast")
- AC1: files.import successfully locates and parses the local school-calendar spreadsheet from the configured `filePath`, returning its schedule/month rows.
- AC2: browser.extract's navigation and login are scoped to the configured school-portal `portalUrl` only, never to an unrelated domain.
- AC3: browser.extract's returned nutritional-information payload corresponds to the same month/schedule window found in the files.import spreadsheet (cross-referenced, not extracted blind).
- AC4: browser.download is only invoked once a complete nutritional-information document is available from browser.extract — no download is attempted from a partial or failed extraction.
- AC5: The downloaded file lands at the configured local `destinationPath`, and browser.download is invoked at most once per run (no duplicate downloads of the same monthly document).
