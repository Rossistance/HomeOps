FamiliOS Privacy Policy

FamiliOS is a household-management application. Users create a household account, invite members, and use the application to organize calendars, tasks, meals, documents, and reminders with the help of an in-app assistant.

What we collect

Information that users enter themselves: calendar events, tasks, meals, files, conversations with the in-app assistant, and contact methods (email addresses and mobile numbers) that users choose to add to their account.

Text messaging (SMS)

  • Text messages are sent only to registered users whose mobile number has been verified with a one-time code and explicitly opted in inside the application.
  • Messages are application-generated: account notifications and reminders for events and tasks the user has set up, one-time phone-verification codes, and replies to queries a user texts to the FamiliOS number.
  • No marketing messages. Phone numbers are never sold, shared, or disclosed to third parties.
  • No mobile information will be shared with third parties or affiliates for marketing or promotional purposes. All other categories of sharing described in this policy exclude text messaging originator opt-in data and consent; text messaging opt-in data and consent will not be shared with any third parties.
  • Reply STOP to any message to opt out, or remove the contact method in the application. Reply HELP for help.
  • Message and data rates may apply. Message frequency varies with account activity.

How data is stored

Account data is stored by the FamiliOS service with secrets encrypted at rest. Third-party services (e.g., Google, Twilio, AI providers) are used only when an account administrator connects them, and only for the features they power.
