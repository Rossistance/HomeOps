FamiliOS SMS Program — Terms & Conditions

Program name: FamiliOS Account Notifications

Program description: FamiliOS is a household-management application. This messaging program sends application-generated messages to registered users who have opted in: account notifications and reminders for calendar events and tasks the user has set up, one-time phone-verification codes, and replies to queries a user texts to the FamiliOS number.

Enrollment / consent

Only registered users can enroll. A user adds their own mobile number inside the FamiliOS application, receives a one-time verification code by text, and confirms it in the application. No number receives recurring messages without completing this verification and opt-in.

Message frequency

Message frequency varies with account activity — typically a few messages per week, plus direct replies whenever a user texts the FamiliOS number.

Fees

Message and data rates may apply according to your mobile carrier plan. FamiliOS itself does not charge recipients for messages.

Opt-out and help

Reply STOP to any message to cancel and stop receiving texts. Reply HELP for help. You can also remove or opt out your contact method inside the FamiliOS application at any time.

Support

For support, email budgetbeacon.ai@gmail.com or use the in-app Messages screen.

Privacy

See our Privacy Policy. Phone numbers are never sold or shared with third parties.
