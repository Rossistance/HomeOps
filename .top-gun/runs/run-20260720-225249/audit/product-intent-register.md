# Product Intent Register

FamiliOS (renamed from HomeOps AI) is an approval-gated family operating system: households start specialized helper agents from a catalog, wire real connectors, and let those agents run automations/skills that touch email, calendar, files, smart home, the web, messaging, and FamiliOS' own household graph — always behind honest approval gates and a "no fabricated success" mandate. This run's scope is narrower: build the 22 source use-cases as FamiliOS templates. Intent below is what the 22 must serve, grounded in the real catalog + tool contracts.

| ID | Claim | Type | Confidence | Evidence IDs | Notes |
|---|---|---|---|---|---|
| PI-01 | The product's job is to turn plain-English household intent into runnable, approval-gated helpers (agents/automations/skills) over real connectors. | goal | confirmed | EV-001,EV-002,EV-010,EV-011 | The planner (`planFromGoal`/`assistantRespond` build kind) already turns a goal into a skill/agent/automation spec — the 22 use-cases are exactly this shape. |
| PI-02 | A shipped "template" is a discoverable starting point (declarative), NOT a runnable unit; the runnable unit is a Skill/Function/Agent/Trigger. | contradiction | confirmed | EV-001,EV-002,EV-003,EV-006,EV-011 | Central architecture truth: building a use-case "as a template" that is also verifiable requires BOTH a catalog entry AND an executable skill. |
