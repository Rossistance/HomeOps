# Visual QA and Screenshot Audit

## Purpose

The previous app versions failed because they built functional surfaces without premium product quality. This audit forces visual inspection.

## Required screenshots

Capture at minimum:

- Desktop dashboard
- Desktop connections
- Desktop agents
- Desktop agent detail or drawer
- Desktop automation builder
- Desktop messages/approvals
- Desktop settings/provider configuration
- Mobile dashboard
- Mobile navigation
- Mobile connections
- Mobile approval flow

## Visual audit rubric

Score each screenshot from 1 to 5.

1 = unacceptable, generic, low quality  
2 = functional but visibly underdesigned  
3 = acceptable SaaS baseline  
4 = premium and polished  
5 = flagship-quality product screen

Minimum passing score:

- No screen below 4
- Dashboard should be 4.5 or better
- Connections should be 4 or better
- Mobile dashboard should be 4 or better

## Mandatory visual checks

- Clear hierarchy
- Premium typography
- Strong first impression
- Sophisticated spacing
- Consistent components
- Polished mobile layout
- No cramped tables
- No generic repeated cards
- No dead whitespace
- No low-effort empty states
- No placeholder/demo labels
- No misleading connected states
- No fake success messages

## If the visual audit fails

Do not write a report claiming success.

Return to design implementation.

Common fixes:

- Rebuild dashboard composition
- Replace flat grids with layered panels
- Improve hero sections
- Improve typography scale
- Improve screen-specific layouts
- Add richer interaction states
- Improve connector status visuals
- Improve approval cards
- Improve mobile detail drawers
