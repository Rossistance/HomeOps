# Design System and Visual Quality Bar

## Design-system goal

Replace the current basic Tailwind component feel with a cohesive premium design system.

The design system must include:

- App shell
- Top command area
- Cards
- Panels
- Drawers
- Modals
- Approval cards
- Agent cards
- Connector cards
- Status badges
- Tool manifests
- Timeline items
- Family member chips
- Document rows
- Mini app containers
- Empty states
- Error states
- Configuration states
- Skeleton/loading states

## Visual density

The app must support a serious amount of information without feeling cluttered.

Use:

- Layered panels
- Clear section hierarchy
- Smart grouping
- Rich card headers
- Progressive disclosure
- Secondary metadata
- Status chips
- Detail drawers

Avoid:

- Repeating identical cards
- One flat grid per screen
- Generic section titles
- Weak empty space
- Oversized icons with little information
- Default-looking buttons

## Typography

Use a refined type system:

- Strong page titles
- Warm supportive subcopy
- Small uppercase labels only where useful
- Consistent numeric and metadata treatment
- Readable mobile sizing
- No cramped form/table text

## Color

Use color intentionally:

- Green/sage for healthy/success
- Amber for needs attention
- Coral/red for risk or blocked
- Lavender for sensitive/caregiving
- Sky/blue for connected/informational
- Deep ink/navy for navigation and trust
- Warm sand/cream for family/home surfaces

Do not overuse bright colors.

## Premium checklist

Each major screen must pass:

- Looks intentional at a glance
- Has a clear hero or organizing principle
- Uses meaningful hierarchy
- Has polished empty/error/loading states
- Avoids generic dashboard layout
- Uses consistent components
- Looks good in desktop and mobile screenshots
- Could plausibly be shown in a product landing page
- Does not include demo/mock labels
